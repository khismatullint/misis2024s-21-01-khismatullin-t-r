1. Клонируйте или скачайте репозиторий с кодом
2. Убедитесь, что у вас установлены библиотеки OpenCV и MRPT (например,
через пакетные менеджеры или сборку из исходников).
3. Зайдите в корневую папку проекта и выполните команду:
mkdir build && cd build && cmake .. && make
4. Запустите программу, использовав флаг –tune. Убедитесь, что в корневой
директории у вас есть dataset/culane/train, например :
./src/RANSAC2 –tune
5. Запустите программу, передав путь к видеофайлу. Например:
./bin/main ../data/polos.mp4
Если нужна рекалибровка вручную птичьего вида или HSV-параметров,
при запуске можно отвечать «y» на вопросы в консоли и использовать
появляющиеся окна с ползунками.
6. При корректном запуске в окне будет отображаться результат с
детектированными линиями. В консоли появятся сообщения о времени
вычисления.
